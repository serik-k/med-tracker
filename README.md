# 🚑 MedTracker — Система Отслеживания Скорой Помощи (Real-Time Ambulance Tracker)

**MedTracker** — это инновационное веб-приложение для частных медицинских клиник в Казахстане (г. Алматы) и СНГ. Система позволяет оперативно отслеживать движение машин скорой помощи в реальном времени по сгорающим веб-ссылкам без необходимости установки приложений пациентом.

---

## 🌟 Ключевые Возможности

- 📱 **Экран Пациента (Живой трекинг):**
  - Живое движение скорой на карте с реальной геометрией дорог (OSRM API).
  - Расчет времени прибытия (ETA) и расстояния.
  - Форма уточнения доступа: домофон, шлагбаум, этаж, фото подъезда.
  - Триаж симптомов и памятка подготовительных действий до приезда врача.
  - **Сгорающие ссылки:** ссылка автоматически инвалидируется после завершения вызова водителем.

- 🖥️ **Кабинет Диспетчера:**
  - Форма быстрой генерации вызова.
  - Кнопка «Открыть в WhatsApp» (`wa.me`) с предзаполненным вежливым текстом и ссылкой.
  - Мониторинг всего автопарка клиники на единой карте.
  - Реальный геокодинг адресов г. Алматы (Nominatim API).

- 🚗 **Интерфейс Водителя:**
  - Мобильная PWA-адаптивная верстка.
  - Управление статусами в 1 клик (*Принял вызов ➔ В пути ➔ Прибыл ➔ Госпитализация ➔ Завершить*).
  - Кнопка прокладки маршрута в **Яндекс Навигаторе** в 1 клик.

- 🌐 **Мультиязычность (i18n):**
  - 🇰🇿 **Қазақша (KK)**
  - 🇷🇺 **Русский (RU)**
  - 🇬🇧 **English (EN)**

## 🛠️ Стек Технологий

- **Frontend:** Vue 3 (Composition API + TypeScript + Script Setup), Pinia, Tailwind CSS, Leaflet.js, Lucide Icons.
- **Backend:** Node.js, Express.js, Socket.io (WebSockets).
- **Services:** OpenStreetMap Nominatim (Geocoding), OSRM Routing Machine (Real Road Geometry).

## Multi-tenant B2B доступ

MedTracker поддерживает несколько медицинских организаций. Бригады, вызовы и realtime-комнаты изолированы по клинике, определяемой из серверной сессии сотрудника.

- `/platform` — управление организациями для администратора MedTracker.
- `/admin` — управление автопарком текущей клиники.
- `/dispatcher` — вызовы только текущей клиники.
- `/driver-access/:token` — защищённая ссылка бригады без регистрации водителя.
- `/track/:token` — временная ссылка пациента без регистрации.

Демонстрационные учётные записи для локальной разработки:

- `platform@medtracker.kz` / `Admin123!`
- `admin@medclinic.kz` / `Clinic123!`
- `dispatcher@medclinic.kz` / `Dispatch123!`
- `admin@sana.kz` / `Clinic123!`

В production пароли начальных аккаунтов обязательно задаются переменными `SEED_PLATFORM_PASSWORD`, `SEED_CLINIC_PASSWORD` и `SEED_DISPATCHER_PASSWORD`.

## PostgreSQL

Скопируйте `.env.example` в `.env`, замените все пароли и запустите инфраструктуру:

```bash
docker compose up --build
```

Контейнер backend автоматически применяет SQL-миграции. Для однократного переноса существующих данных из JSON выполните до переключения приложения на PostgreSQL:

```bash
npm --prefix server run db:import-json
```

Импорт идемпотентен: повторный запуск не создаёт дубликаты. JSON-хранилище остаётся активным на переходном этапе, пока серверные репозитории полностью не переведены на PostgreSQL.
