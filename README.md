# 🚑 MedTracker — Система Отслеживания Скорой Помощи (Real-Time Ambulance Tracker)

**MedTracker** — это инновационное веб-приложение для частных медицинских клиник в Казахстане (г. Алматы) и СНГ. Система позволяет оперативно отслеживать движение машин скорой помощи в реальном времени по сгорающим веб-ссылкам без необходимости установки приложений пациентом.

---

## 🌟 Ключевые Возможности

- 📱 **Экран Пациента (Живой трекинг):**
  - Живое движение скорой на карте с реальной геометрией дорог (OSRM API).
  - Расчет времени прибытия (ETA) и расстояния.
  - Форма уточнения доступа: домофон, шлагбаум, этаж, фото подъезда.
  - Триаж симптомов и памятка подготовительных действий до приезда врача.
  - **Сгорающие ссылки:** ссылка автоматически инвалидируется после завершения вызова водителем.

- 🖥️ **Кабинет Диспетчера:**
  - Форма быстрой генерации вызова.
  - Кнопка «Открыть в WhatsApp» (`wa.me`) с предзаполненным вежливым текстом и ссылкой.
  - Мониторинг всего автопарка клиники на единой карте.
  - Реальный геокодинг адресов г. Алматы (Nominatim API).

- 🚗 **Интерфейс Водителя:**
  - Мобильная PWA-адаптивная верстка.
  - Управление статусами в 1 клик (*Принял вызов ➔ В пути ➔ Прибыл ➔ Госпитализация ➔ Завершить*).
  - Кнопка прокладки маршрута в **Яндекс Навигаторе** в 1 клик.

- 🌐 **Мультиязычность (i18n):**
  - 🇰🇿 **Қазақша (KK)**
  - 🇷🇺 **Русский (RU)**
  - 🇬🇧 **English (EN)**

## 🛠️ Стек Технологий

- **Frontend:** Vue 3 (Composition API + TypeScript + Script Setup), Pinia, Tailwind CSS, Leaflet.js, Lucide Icons.
- **Backend:** Node.js, Express.js, Socket.io (WebSockets).
- **Services:** OpenStreetMap Nominatim (Geocoding), OSRM Routing Machine (Real Road Geometry).

---

## 🚀 Быстрый запуск

### 1. Запуск Backend:
```bash
cd server
npm install
npm start
```

### 2. Запуск Frontend:
```bash
cd client
npm install
npm run dev
```
